DeployMate

Lightweight GitOps Deployment Engine

Go • Kubernetes • PostgreSQL • Redis ● Built from scratch

Architecture

Engine API

Chi router, OIDC auth, Redis cache (5s TTL), PostgreSQL with JSONB. Serves desired state to agents.

Edge Agents

Lightweight Go binaries polling every 10s. client-go reconciliation. OPA policy enforcement at edge.

Multi-Cloud

Unified Deployer interface: Kubernetes, Cloud Run, ECS Fargate, VMs via SSH. Same API, different backends.

Policy Engine

OPA Rego evaluation. Dual eval: central (pre-deploy) + edge (drift detection). Sigstore bundle signing.

Preview Envs

PR-triggered preview environments. GitHub webhook → unique namespace → auto-destroy on close.

Real-Time

SSE event streaming. Dashboard receives deployment.progress, health.check, rollback events live.

Policy-as-Code

🛡 OPA Rego Policies

Deployments evaluated against Rego policies at central and edge.

• CPU limits enforced
• Image provenance verified
• Production requires approval
• Cost thresholds checked

🔐 Sigstore Signing

Policy bundles signed with Sigstore keyless signing.

• No key management overhead
• OIDC-based identity
• Transparency log (Rekor)
• 48h bundle staleness tolerance

🔄 Dual Evaluation

Central: Pre-deploy gate blocks non-compliant deployments.

Edge: Runtime drift detection triggers autonomous rollback.

📦 Bundle Distribution

Engine signs → agents verify → cache locally.

• Survives engine outages
• Incremental updates
• Tamper-evident via Rekor

Instant Rollback

One-click rollback. 3/hr guardrail. Agent reconciles in <10s.
